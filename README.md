# Tobacconery: Smoking (аддон для Create: Tobacconery 1.0.2, NeoForge 1.21.1)

## Что делает
- **Слот «Рот» (Curios).** Клавиша **G**: зажжённая сигарета из руки -> в рот; повторно -> достать.
  Во рту сигарета видна на лице, дымит и догорает (съедает прочность, как у Tobacconery), потом исчезает.
  Под водой/дождём не тлеет.
- **Курение с поднесением ко рту** (удержание ПКМ): зажжённые сигареты, трубка (`filled_wooden_pipe_regular`),
  вейп (`vape`), шланг кальяна (`hookah_hose`). Первое лицо: предмет едет к центру экрана.
  Третье лицо: рука модели поднимается ко рту (видят и другие игроки).
- **Пачки:** пока открыто радиальное меню выбора сигареты, пачка в первом лице поднимается к груди.

## Сборка
1. Скачайте MDK NeoForge 1.21.1 (github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle) и скопируйте из него в эту папку
   `gradlew`, `gradlew.bat` и папку `gradle/` (в архиве проекта их нет).
2. Откройте `gradle.properties`: `neo_version` должна совпадать с вашей версией NeoForge,
   `curios_version` проверьте на https://maven.theillusivec4.top/
3. `./gradlew build` -> готовый мод в `build/libs/`. Положите его в `mods` рядом с Tobacconery и Curios.
4. Тест из IDE: `./gradlew runClient`, предварительно положив jar Tobacconery и Curios в `run/mods/`.

## Что нужно подкрутить после первого запуска
- Все числа поз в `client/SmokeTuning.java` (положение руки и предмета).
- Скорость горения во рту: `DAMAGE_PER_STEP` / `STEP_TICKS` в `MouthSlotHandler.java`
  (сверьте со скоростью горения сигареты в обычном инвентаре).
- Положение сигареты на лице задаёт блок `display.head` в моделях самого Tobacconery.

## Известные ограничения
- Проект не компилировался и не запускался: при написании не было доступа ни к игре, ни к Gradle.
- Эффекты курения Tobacconery даёт при удержании ПКМ; сигарета во рту только дымит и тлеет.
- Анимацию пачки видите только вы (радиальное меню локальное), у других игроков её нет.
- Если версия Curios 9.x использует другие пути данных, слот может не появиться: смотрите лог на `curios`.
